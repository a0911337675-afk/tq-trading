# 交易的演化史｜15 篇完整網站文章目錄

> 從交易起源、程式交易、量化交易到 AI 交易的完整系列文章導讀。

> ⚠️ 風險提醒：本文為交易歷史與研究整理，不構成投資建議。任何策略在不同市場、不同週期、不同執行成本下，結果都可能完全不同。


## 系列文章目錄

- [第一章｜交易的起源：從股份公司到現代市場](./01_trade_origin.md)：從 1602 年荷蘭東印度公司、阿姆斯特丹交易所，到現代股票市場的基本雛形。
- [第二章｜人工喊價時代：交易員、交易池與資訊優勢](./02_open_outcry.md)：介紹 Open Outcry、交易大廳、經紀人制度，以及資訊速度如何成為早期市場的核心獲利來源。
- [第三章｜數學正式進入金融：從平均數到投資組合理論](./03_math_enters_finance.md)：整理平均數、標準差、共變異數、Markowitz 投資組合理論、CAPM 與 Sharpe Ratio 的金融意義。
- [第四章｜技術分析黃金年代：大眾最常用的交易公式](./04_technical_analysis.md)：整理 SMA、EMA、RSI、MACD、KD、布林通道、ATR、VWAP 等最普及指標。
- [第五章｜程式交易的誕生：國外何時開始自動化交易](./05_program_trading_birth.md)：介紹 1970–1990 年代電子報價、程式交易、Portfolio Insurance 與自動下單的發展。
- [第六章｜傳奇量化基金：從 Jim Simons 到現代 Quant](./06_quant_funds.md)：介紹 Renaissance Technologies、Medallion Fund、D. E. Shaw、Citadel、Two Sigma、AQR 等代表性量化機構。
- [第七章｜高頻交易：速度、延遲與市場微結構](./07_high_frequency_trading.md)：深入介紹 HFT、Latency、Co-location、FPGA、Market Making、Order Book 與 Flash Crash。
- [第八章｜統計套利：Z-score、配對交易與均值回歸](./08_statistical_arbitrage.md)：介紹 Pairs Trading、Cointegration、Z-score、Kalman Filter、PCA 等統計套利核心方法。
- [第九章｜現代量化交易系統：從 Python 到 API 自動下單](./09_modern_quant_system.md)：介紹現代量化系統架構、資料、回測、風控、實盤執行與監控。
- [第十章｜AI 如何改變交易：從機器學習到大型語言模型](./10_ai_machine_learning.md)：介紹 Random Forest、XGBoost、LightGBM、LSTM、Transformer、強化學習與 LLM 在交易中的角色。
- [第十一章｜加密貨幣量化：24 小時市場的新實驗場](./11_crypto_quant.md)：介紹 BTC、ETH、永續合約、資金費率、清算、API、Order Flow 與加密市場量化特色。
- [第十二章｜真正長期存在的策略：趨勢、均值、套利與做市](./12_profitable_strategies.md)：整理 Momentum、Trend Following、Mean Reversion、Carry、Volatility、Market Making、Pairs Trading 等長期存在的交易型態。

- [第十四章｜現代大型量化公司：技術、人才與護城河](./14_major_quant_firms.md)：整理現代量化公司如何靠資料、工程、研究流程、風控與執行效率建立競爭力。
- [第十五章｜未來十年交易會如何演變：AI Agent、量子運算與自適應系統](./15_future_of_trading.md)：展望未來交易模式，包含 AI Agent、多策略自適應、LLM 研究助理、量子運算與監管變化。
